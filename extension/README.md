# flip Chrome extension

Reads a listing page through your own browser, where Zillow and Redfin
already let you in, and adds an "Analyze in flip" button on listing pages.

Install (unpacked, until it is on the Chrome Web Store):

1. Download and unzip `flip-extension.zip` from the app, or use this folder.
2. Open `chrome://extensions`, turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick the folder.

Then in flip, paste a listing link and press Analyze: the app fetches the
page through the extension. Or click "Analyze in flip" on any listing.
